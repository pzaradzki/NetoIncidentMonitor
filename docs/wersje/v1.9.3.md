# Neto Incident Monitor 1.9.3

Status: przygotowanie wydania, 5 listopada 2026.

## Co nowego

- Ujednolicono główny status aplikacji, pigułkę sekcji i opis pod dashboardem podczas pobierania danych, ponawiania odczytu, oczekiwania na logowanie oraz błędu. Ponawianie SLA nie pozostawia już głównej pigułki w stanie „Oczekiwanie”.
- Zdarzenia starszych lub zakończonych żądań nie nadpisują bieżących statusów. Końcowy błąd lub sukces zachowuje pierwszeństwo; błąd częściowy pozostaje widoczny po pracy następnej sekcji.
- Dodano bezpieczną diagnostykę zmian statusu UI z identyfikatorem żądania, aliasem sekcji i stałym kodem stanu, bez wartości kafelków i danych formularzy.
- Zachowano logikę odczytów, odzyskiwania sesji, Stop, restartu Chromium, harmonogram, cache, okres i timestamp ostatniego pełnego odczytu.

## Instalacja i aktualizacja

Zamknij monitor, rozpakuj cały ZIP i uruchom `Neto Incident Monitor.exe`. Zachowaj sąsiedni folder `_internal`. Lokalne dane użytkownika są przechowywane poza folderem programu. Po przeniesieniu aplikacji uruchom ją raz ręcznie, aby naprawić wcześniej istniejący autostart.

## Ograniczenia

Zmiana dotyczy prezentacji stanu i nie obiecuje przyspieszenia dashboardu. Wydanie nie zawiera odrzuconego eksperymentalnego obserwatora. Autostart Windows pozostaje domyślnie wyłączony i ukryty w UI. Retencja outbox, lokalizacja logów źródłowych i paginacja zagrożeń SLA z wieloma stronami pozostają osobnymi tematami. Kanał e-mail nie jest częścią wydania.
