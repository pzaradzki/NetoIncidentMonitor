# Neto Incident Monitor 1.12.0-experimental.1

Zastąpiona lokalnie przez [1.12.0-experimental.2](v1.12.0-experimental.2.md), która uruchamia dashboard bez ręcznego kopiowania konfiguracji.

Lokalna paczka testowa z 16 listopada 2026. Punktem wyjścia jest commit `35976fc`. W źródłach tej paczki ustawiono numer eksperymentalny i dostosowano sprawdzanie aktualizacji, aby stabilne `1.12.0` zostało rozpoznane jako nowsze wydanie. Ostatnim opublikowanym wydaniem pozostaje [1.11.2](v1.11.2.md).

Paczka obejmuje migrację odczytów dashboardu, zagrożeń SLA, filtrów i Ulubionych na REST, aktualizację zakresu agentów i lokalizacji oraz trzy nowe kafelki Dashboardu SLA i Wstrzymanych L1.

## Uruchomienie lokalne

W `dist/1.12.0-experimental.1` uruchom `Uruchom wersje testowa.cmd`. Start korzysta z osobnych danych w `%LOCALAPPDATA%\NetoIncidentMonitor-Experimental\NetoIncidentMonitor`. Przy pierwszym uruchomieniu kopiuje wyłącznie lokalną konfigurację dashboardu z katalogu projektu. ServiceNow wymaga zalogowania w osobnym profilu Chromium i skonfigurowania filtrów do testów.

ZIP zawiera EXE i katalog `_internal`. Bezpośrednie uruchomienie EXE używa standardowego profilu aplikacji. Po rozpakowaniu ZIP-a w innym miejscu konfigurację dashboardu przygotuj na podstawie lokalnego arkusza według [instrukcji konfiguracji REST](../servicenow-api-sesja-przegladarki.md).
