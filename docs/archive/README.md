# Archiwum zastąpionych opisów

Zachowujemy historię i powody dawnych propozycji, ale nie używamy ich jako opisu aktualnego działania ani polecenia wznowienia prac.

- [Dawna diagnostyka logowania](authentication-diagnostics-pre-v1.8.0.md) → zastąpiona przez [bieżący kontrakt](../contracts/authentication-diagnostics.md).
- [Dawny plan powiadomień filtrów](custom-filter-notifications-plan.md) → funkcja jest wdrożona; bieżąca obsługa w [instrukcji](../user-guide.md#własny-format-powiadomień-filtra). Notatki zawierają także porzucone warianty.

Zakończone plany stabilizacji zachowano oddzielnie w [plans/completed](../plans/README.md). Decyzje i dowody pomiarowe pozostają we właściwych katalogach.
